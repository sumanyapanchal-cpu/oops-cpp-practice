# OOPS in C++ — Learning & Practice

This repository documents my learning journey through Object Oriented Programming using C++ as part of my B.Tech CSE curriculum.

## Topics Covered

- Classes and Objects
- Data Members and Member Functions
- Access Specifiers
- Encapsulation and Data Hiding
- Scope Resolution Operator
- Constructors
- Default and Parameterized Constructors
- Constructor Overloading

- `Unit-1/` — C++ fundamentals and OOP basics

- `Unit-3/` — Inheritance and Polymorphism
- `Unit-4/` — Advanced C++ concepts

- Prepare for university practical examinations and viva voce.
- Maintain a record of programs and concepts covered.
